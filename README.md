# 数学関数集

大学数学でよく出てくる関数を、説明とインタラクティブなグラフで確認できる Web アプリ。
スライダーでパラメータを変えると、グラフの形がリアルタイムに変わる。

## 収録予定の関数

- [x] シグモイド関数
- [ ] tanh（双曲線正接）
- [ ] ReLU
- [ ] 正規分布の確率密度関数
- [ ] 三角関数（振幅・周期・位相）

## 使い方

`index.html` をブラウザで開くだけ。ビルド不要。

ローカルサーバーで見る場合:

```bash
python3 -m http.server 8000
# → http://localhost:8000
```

## 技術

- HTML / CSS / JavaScript（フレームワークなし）
- グラフ描画は Canvas API を直接使用

## 開発メモ

- ブランチを切って機能を作り、`main` にマージする
- `main` は常に動く状態を保つ
